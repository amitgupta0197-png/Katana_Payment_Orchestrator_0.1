# Katana Agent — Full Setup Tutorial (Production Script)

**Format:** 9:16 vertical (1080×1920) · **Length:** ~90s · **Voiceover:** Hindi · **Captions:** English (burned-in) · **Music:** upbeat, low volume.

**Goal:** Show a merchant, step by step, how to enable EVERY setting so Katana captures each UPI payment's RRN automatically.

> **Device note:** ColorOS/OnePlus (and most Android phones) open a system screen for each permission where you flip a toggle or tap **Allow**. The pattern is the same for every permission: **tap the row in the app → the system screen opens → turn it ON / tap Allow → press Back.** The video demonstrates this live for the Screen Reader (the trickiest one); the rest follow the identical pattern.

## Voiceover — full Hindi read (for ElevenLabs / recording)

> Katana Agent setup — sirf do minute mein.
> App kholein. Upar likha aata hai "Agent active".
> Sabse pehle PERMISSIONS. Bank SMS par tap karke Allow karein.
> Fir Notification access — Katana ko ON karein.
> Background activity bhi Allow karein, taaki app kabhi band na ho.
> Ab sabse zaroori — Screen reader. Settings mein Katana Agent ko ON karein aur "Allow" dabayein. Yahi Paytm screen se RRN uthata hai.
> Display over other apps bhi ON karein.
> App mein wapas aakar, Auto-capture ON karein.
> Apna merchant code daalein — jo Katana team deti hai — aur Save karein.
> Bas! Saari settings ON. Paytm Business ko payments list par khula rakhein.
> Ab har payment ka RRN apne-aap capture hoga. Ho gaya!

**Tone:** friendly, confident, unhurried. ~150 words → ~90s.

## How to assemble (easy → amazing)
1. **Beautify:** import the clips into **Screen Studio** (Mac) — auto zoom-on-tap + cursor make it look premium. Free alt: **CapCut**.
2. **Fill the still scenes (3,4,5,7):** the system-permission screens can't be auto-recorded on this ColorOS phone, so use the PNG references with a gentle zoom (Ken Burns) while the VO plays — or screen-record those 3 taps yourself on a fresh phone and drop them in. The `seg-accessibility.mp4` live demo shows viewers the exact pattern for all of them.
3. **Voiceover:** paste the Hindi read into **ElevenLabs** (warm Hindi voice) → MP3 → lay under the footage.
4. **Captions + music:** CapCut auto-captions with the English lines; soft upbeat track at ~15%.
5. **Export:** 1080×1920 MP4, under ~15 MB for instant WhatsApp playback.
